# ez-action

A minimal task tracker that just works.

## UI

Just like the other ez-mini apps, there exists a navbar.

- Top right is the three dots menu with the same features as ez-blank and ez-repeat
- Top left is a hamburger menu that opens a sidebar with categories. The categories are:
    - Today
    - Planned
    - Unplanned
    - Then there's a horizontal bar and then user made lists which the user can create with a button on the bottom right of the side bar
